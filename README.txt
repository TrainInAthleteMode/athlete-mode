ATHLETE MODE — iPhone web app prototype

WHAT'S INCLUDED
- Four-day upper/lower strength + explosive workout split
- Exercise checklists and technique instructions
- Rest timer
- Local progress and notes
- Optional IndexedDB video library for videos you own or have permission to save
- PWA manifest and service worker for offline app-shell caching

IMPORTANT
This is a prototype, not an App Store app. For reliable home-screen installation and service-worker/offline support, host these files on an HTTPS website. Free hosting options include GitHub Pages. After deploying, open the website in Safari on your iPhone, tap Share, then Add to Home Screen. Open it once while online before using offline.

OFFLINE VIDEO
The app can import a video file selected from Files and store it in browser IndexedDB, subject to iOS storage limits. Test playback after adding it to the Home Screen. Do not clear Safari website data if you want to keep saved progress/videos. External demonstration search links need internet. Only save videos you have permission to download.

SAFETY
Use manageable weights and good technique. Get qualified supervision for unfamiliar lifts and explosive drills. Stop if something hurts or technique breaks down.
